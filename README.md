# Linux + Python + AI Lab

A personal laboratory for Linux, Python, automation and AI experiments.

This repository is built around small, practical projects that can be run on Ubuntu/Linux and gradually connected to real engineering workflows.

## Roadmap

- **01-linux-basics** — Learn Linux through useful shell scripts.
- **02-terminal-fun** — Small terminal experiments and visual effects.
- **03-python-linux** — Python tools for system administration and automation.
- **04-network** — Networking utilities for learning and troubleshooting.
- **05-linux-automation** — Backups, cleanup, health checks and setup scripts.
- **06-ai** — AI-assisted terminal and log-analysis experiments.
- **07-ivd-tools** — Future tools for IVD instrument logs and engineering data.

## Philosophy

The goal is not to collect commands. The goal is to turn Linux, Python and AI into practical engineering tools.

Projects should be small enough to understand, useful enough to keep, and extensible enough to become larger tools later.

## Requirements

Most projects target Ubuntu 22.04+ and modern Python 3. Some experiments may require additional packages; each project should document its own dependencies.
